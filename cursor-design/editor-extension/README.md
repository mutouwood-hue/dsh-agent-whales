# Whales Design Canvas 0.2.0

Install this VSIX in Cursor and configure the matching Whales Design MCP server for your project. Generated artboards appear in a draggable, connected canvas with interactive previews and element feedback.

Use **重新渲染** to retry a timeout or reload the current board. **全屏** opens the board in a dialog inside the current editor view; press Escape or close it to return. Select a board and drag its border handles to resize the frame. Frame sizes, positions and connections persist in `.whales-design/canvas.json`.

Requires Node.js 22+ for the companion MCP server. Download the standalone MCP package from the same GitHub release. See [setup instructions](https://github.com/mutouwood-hue/dsh-agent-whales/blob/cursor/cursor-design/README.md). DSH team and office features are outside this design adapter.
