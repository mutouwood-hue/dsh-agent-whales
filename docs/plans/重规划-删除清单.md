## 0. 铁律

1. **不删任何用户数据存储**：`projects.json`、`canvas.json`、`proposals.json`、`handoffs.json`、`events.json`、`briefs`、`e2e/` 目录原样保留，旧数据必须仍然能读。删的是**界面和多余的规则**，不是数据。
2. 每一步**先测试后改**；大删改前后 `npm test` 都必须绿；删掉的功能对应的测试**一并删除并在下表写明**，不留「被注释掉」的死测试。
3. 局部替换改 `lib/index.js`、`lib/client.js`，禁止整文件覆盖。
4. 每一步一个提交、通过后直接推送；每一步用真浏览器（桌面版 0.2.2-rc.5 的 CLI 起的隔离实例 + Tabbit）看截图。
5. 被合并的功能**要有去处**；被砍的功能**要在本表写明理由**，不悄悄消失。
