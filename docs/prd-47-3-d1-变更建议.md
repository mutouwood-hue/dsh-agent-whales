## 二、逐条变更点

### 变更 1 · §47.3 D1（接管路径）★核心

- **原文**：「做 P0（画布 View）→ P1 影子 composer → P1.5 影子 chat.node → P2 侧边栏；不做整页替换」→ 决定 W1/W2 范围
- **改为**：「做 P0 → P1 → P1.5 → P2；**明确禁止 P3（整页替换）**；P2 独立主面板的**主形态定为节点图画布**（卡片 + 连线 + 空态引导，设计稿 T-1/T-4），**暗色为风格选项、默认浅色**（§10）」→ 决定 W1/W2 范围 + T 系列设计稿
- **理由**：§45.3 P2 原本只有一句话；「不做整页替换」细化为「禁 P3」，避免与 P1.5（影子 chat.node，官方会话流仍在）混淆

### 变更 2 · §45.3 P2 段落补充

- **补充**：「P2 主面板形态 = 节点图画布：上下文节点（仓库/文件夹）→ Agent → Composer 构成有向数据流；Agent ↔ Agent 为无向关联线（沿用 M6-1 语义，只用于互发与互读）；**任务依赖（blockedBy）不上画布**，归任务板」
- **理由**：连什么、不连什么必须明文，否则实现会画错（任务依赖画上画布是最容易出的偏差）

### 变更 3 · §47.3 新增 D11（连线编辑）

- **新增**：「D11 连线编辑交互：悬停出锚点 / 拖拽虚线预览 / 松手建成 / 点选删除（确认后断）；可连组合 = 上下文→Agent·Composer、Agent↔Agent；禁止自连与重复连线；删上下文节点时提示受影响的 Agent 与进行中任务」→ 决定 W1 交互范围
