# 新表情生成说明（给 GPT / 任何图像模型）

目标：在 **AATINF/deepseek-whale-girl-assets** 这套素材的基础上，补几张现在缺的表情，
风格必须与现有 7 张一致，接进插件后不能"换了个画风"。

> 授权边界：角色参考是 TreapGoGo/deepseek-whale-girl（MIT）；**不要**拿 clawd-on-desk 的
> Whale-chan 主题（CC BY-NC-SA 4.0，非商用+相同方式共享）当素材，两套授权不同源。

## 一、怎么把图交给模型

1. 打开素材包里任意一张 **Q 版正面/3-4 侧全身**（推荐 `C12`，就是我们现在的 `q-smile`），
   作为**参考图（image-to-image 的角色锁）**一起上传。
2. 把下面「角色锁定」整段原样粘进提示词——它来自素材包 manifest.csv 的原始 prompt，
   是这批图的统一角色描述，复用它才能保证同一个人。
3. 每个表情单独生成一次，**一次只要一张、只要一个角色**。

## 二、每次都要带上的约束（照抄）

```
【输出要求】只画一个角色、单幅画面：不要分栏、不要拼版、不要多视图并排、不要网格边框或格线、
不要文字标注或箭头说明、不要水印、不要 UI 按钮或滚动条、不要角色设定表的版式。
纯白背景，脚下柔和落影，平视镜头，人物居中，全身完整入画（必须包含鞋子与身后鲸尾）。
画风：精致的日系动漫插画上色（干净的赛璐璐平涂 + 柔和渐变，清晰锐利的线稿）。
Q 版比例（大头小身），与参考图同一角色。
```

## 三、要补的 6 个表情（建议顺序）

| key（文件名） | 表情 | 动作提示 |
| --- | --- | --- |
| `q-laugh` | 大笑 | 张嘴大笑、眼睛弯成月牙，双手举到胸前，身后鲸尾翘起 |
| `q-surprise` | 惊讶 | 眼睛睁大、嘴巴成小圆，双手微抬，呆毛立起 |
| `q-pout` | 不满/鼓脸 | 鼓腮、眉头微皱、双手抱胸，尾巴微垂 |
| `q-shy` | 害羞 | 脸颊泛红、眼神躲闪、双手在身前提裙角，低头浅笑 |
| `q-think` | 思考 | 一只手托腮、视线向上、尾巴慢慢摆，表情认真 |
| `q-sleep` | 打瞌睡 | 闭眼、脑袋微垂、嘴角有小气泡/流口水，站姿松垮 |

> 已有、不用再做：微笑（`q-smile`）、眨眼（`q-blink`）、挥手（`q-wave`）、得意（`q-proud`）、抱膝（`q-sleepy`）。

## 四、交图规格

- **PNG**，长边 ≥ 1024，**纯白或近白背景**（管线靠白底洪水填充抠图，灰底/渐变底会抠不干净）
- 文件命名就是 key：`q-laugh.png`、`q-surprise.png`……
- 丢进 `D:\干活\dsh-agent-whales\_incoming\`
- 然后跑：

```powershell
python tools/ingest-generated.py _incoming
node tools/embed-art.mjs
node --test test/client.test.mjs
```

`ingest-generated.py` 会做和现有素材完全相同的处理（抠白底 → 去溢色 → 收边 → 预乘缩放 → WebP 192px），
并合并进 `assets/art.json`；`embed-art.mjs` 再内联进 `client.js`。

## 五、接进来之后怎么用

素材表里有了新 key，客户端还**不会自动用**——需要把它们挂到状态机上。挂点在各一处：

- `lib/client.js` 的 `Q_FRAMES`：`{ base, blink, entry, exit, sleepy }` 五个槽，可把新表情塞进
  `entry`（换掉挥手）、`exit`（换掉得意）、`sleepy`（换掉抱膝），或新增事件帧（完成/惊讶）。
- 表情轮换想更活泼，可以给 `frameOf()` 加一个 `mood` 变体，配合 `QUIPS` 的轮换 tick 换帧。

改完记得跑测试：现有断言会检查每个精灵的尺寸与 data URI 合法性，能挡住"图坏了/尺寸不对"。
